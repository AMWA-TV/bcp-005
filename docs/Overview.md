## Introduction

The BCP-005 series defines mappings between external capabilities or protection technologies and the NMOS capability model. These recommendations make technology-specific endpoint capabilities discoverable and usable by NMOS Controllers.

The suite currently includes:

- [BCP-005-01: NMOS EDID to Receiver Capabilities Mapping](https://specs.amwa.tv/bcp-005-01) describes how EDID information is expressed through Receiver Capabilities.
- [BCP-005-02: NMOS Support for IPMX/HKEP](https://specs.amwa.tv/bcp-005-02) describes support for HDCP over IP streaming using IPMX/HKEP.
- [BCP-005-03: NMOS Support for IPMX/PEP](https://specs.amwa.tv/bcp-005-03) describes support for Privacy-encrypted streaming using IPMX/PEP.

The recommendations should be read alongside:

- [BCP-004-01: NMOS Receiver Capabilities](https://specs.amwa.tv/bcp-004-01)
- [BCP-004-02: NMOS Sender Capabilities](https://specs.amwa.tv/bcp-004-02)
- [IS-04: NMOS Discovery and Registration](https://specs.amwa.tv/is-04/)
- [IS-05: NMOS Device Connection Management](https://specs.amwa.tv/is-05/)
- [NMOS Parameter Registers](https://specs.amwa.tv/nmos-parameter-registers/)
