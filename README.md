# AMWA BCP-005: NMOS Capability Mappings

This repository holds the suite overview for the BCP-005 series of AMWA Best Common Practices, part of the family of [Networked Media Open Specifications](https://specs.amwa.tv/nmos) from the [Advanced Media Workflow Association](https://amwa.tv).

<!-- INTRO-START -->

### What does the suite do?

- The BCP-005 series defines mappings between external capabilities or protection technologies and the NMOS capability model.
- It describes how NMOS Senders, Receivers, and Controllers declare and use support for specific technologies.

### Why does it matter?

- Consistent mappings allow Controllers to reason about endpoint capabilities using NMOS mechanisms.
- The recommendations make technology-specific capabilities discoverable and interoperable without requiring vendor-specific extensions.

### What are the recommendations?

- [BCP-005-01: NMOS EDID to Receiver Capabilities Mapping](https://specs.amwa.tv/bcp-005-01)
- [BCP-005-02: NMOS Support for IPMX/HKEP](https://specs.amwa.tv/bcp-005-02)
- [BCP-005-03: NMOS Support for IPMX/PEP](https://specs.amwa.tv/bcp-005-03)

## Getting started

Choose the recommendation for the capability or protection technology being integrated:

- [BCP-005-01](https://specs.amwa.tv/bcp-005-01) for EDID-to-capability mapping
- [BCP-005-02](https://specs.amwa.tv/bcp-005-02) for IPMX/HKEP
- [BCP-005-03](https://specs.amwa.tv/bcp-005-03) for IPMX/PEP

There is more information about the NMOS Specifications and their GitHub repositories at <https://specs.amwa.tv/nmos>.
